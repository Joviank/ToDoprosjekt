Hvordan sette dette opp:

1. Lag HomeController.cs for Razor-view

2. Lag alle filene i Views. Dette blir vår "HTML" del.

3. Lag wwwroot, legg til styling som du ønsker og JavaScript. JavaScript er viktig for å kunne la frontend kommunisere med backend.

4. Lag en traefik.yml fil eller valgfritt ingress Controller.

5. Legg til ingress Controller i docker compose service og gi api en label.

6. Legg til volumes i docker-compose.yaml

7. Legg til AddControllersWithViews for razor page, legg til static og Routing og endre mapControllerRoute

8. Docker compose up --build (Husk å start opp docker desktop)
Hvis databasen ikke kjører: dotnet ef database update

9. Test ut apiet, frontend, swagger, pgadmin osv.
